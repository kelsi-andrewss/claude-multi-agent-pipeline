**Library check:** Before generating, read `<project-root>/components/ui/manifest.json` if it exists. Matched components → import directly, skip gemini_ui_code. Unmatched → generate. After build, append novel components to manifest.

1. Prepare all contracts — classify greenfield vs brownfield per component

4. Build once, fix broken (max 3 rounds) — circuit breaker → NEED_DECISION after same error twice OR 3 rounds
