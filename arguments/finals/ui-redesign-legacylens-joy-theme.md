# Argue: UI redesign concept for LegacyLens — joy and excitement theme
**Type**: general  **Rounds**: 4  **Converged**: yes
**Date**: 2026-03-04

## Synthesis

**Agreed position:** The LegacyLens UI should use an **"Unlocking/Revealing"** metaphor — the satisfaction of discovery, puzzle pieces clicking into place, fog clearing to reveal understanding. Not a place you visit (observatory), not a machine you operate (cockpit/vault), but an experience of *things becoming clear*.

### Converged Design Principles

**Base palette — Carbon & Charcoal:**
- Ultra-dark grays/charcoals (not void-black, not navy) for optimal sustained reading
- High contrast for code without harshness

**Accent palette — Stable Semantic Colors:**
- **Electric Cyan**: dependencies, structural/logic connections (cool, objective)
- **Soft Amber**: AI explanations, human-facing warmth (where the AI communicates)
- **Magenta**: highlights, warnings, "click" moments of excitement (the energy color)
- Colors are *meaning*, not *mood* — no shifting, no atmospheric color pollution

**Typography — Swiss Precision:**
- Neo-grotesque sans-serif for UI (high legibility, scientific authority without elitism)
- Modern high-x-height monospace for code
- Conveys competence without exclusion

**Animation — Local Specular Highlights:**
- No global atmospheric effects (aurora/neon shifts destroy semantic color reliability)
- Active elements brighten with local "specular" glow; inactive elements recede
- Transitions use optical-lens-focusing curves (high-speed but smooth, not binary toggles)
- Inactive elements remain as structural ghost-map providing context

**Joy Mechanism — Semantic Tracers + Snap-to-Focus:**
- Visual connections between Fortran source and AI explanations (tracers)
- Discovery moments feel like "snapping into focus" — satisfying, precise, weighted
- The emotional register is accessible: "look what I found" not "system online"

### Key Debate Insights

1. **Intensity fatigue is real**: Constant maximum energy (neon everything) becomes friction after 50 queries
2. **Chromatic ambiguity kills usability**: Shifting background colors conflict with semantic color coding — color must encode meaning, not atmosphere
3. **Metaphors can exclude**: "Starship pilot" and "Master Machinist" both gate-keep. "Discoverer" is universal
4. **Precision and joy coexist**: Swiss typography + specular highlights = a tool that's reliable AND delightful
